# 🪟 DSH Desktop Notify - 桌面通知插件

## 📖 简介

把 DeepSeek Harness 里的关键事件——会话完成、出错、提问、等待审批、后台任务结束——转化为 Windows 系统通知，让你在处理其他事务时也能及时知晓。

## ✨ 核心功能

### 何时会收到通知？

| 触发时机 | 通知标题 | 通知内容 |
| :--- | :--- | :--- |
| 一轮对话正常结束 | 会话完成 | 显示会话标题（如有），并提示可继续对话 |
| 一轮对话发生错误 | 会话出错 | 显示错误摘要信息 |
| Agent 向你提问 | 需要你的回答 | 显示问题原文（如有多个问题，会标注数量） |
| 工具调用待你审批 | 等待你的批准 | 显示工具名称及申请原因 |
| 后台任务执行完毕 | 后台任务完成 / 已取消 / 失败 | 显示命令或任务名称及其最终状态 |

### ⚙️ 可用设置项

在 **Plugins** 页面点开本插件即可配置。

| 设置项 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `language` | `zh` | 通知语言：`zh` (中文) / `en` (英文) |
| `sound` | `true` | 是否播放提示音 |
| `turnEnd` | `true` | 是否在回合结束/出错时提醒 |
| `questions` | `true` | 是否在 Agent 提问时提醒 |
| `approval` | `true` | 是否在等待批准时提醒 |
| `jobs` | `true` | 是否在后台任务结束时提醒 |
| `childSessions` | `false` | 是否允许子会话的通知也弹出 |

### ⚠️ 已知限制

- **平台支持**：仅在 Windows 上经过完整测试。macOS/Linux 有备选实现 (`osascript` / `notify-send`)，但未经充分验证。
- **会话定位**：点击通知不会自动选中对应会话，需手动在侧边栏选择。
- **通知可见性**：如果未看到横幅通知，请检查 Windows 通知中心（Win + N）或系统 `设置 → 系统 → 通知` 中的横幅开关。

## 🚀 安装指南

**前置条件**：已在 Windows 上安装 DeepSeek Harness。

### 从 GitHub 安装（推荐）

1.  在 DSH 侧边栏进入 **Plugins → 安装**。
2.  输入仓库地址：
    ```
    https://github.com/endll/dsh-desktop-notify
    ```
3.  点击安装即可。

### ✅ 安装后验证

1.  **重启 DeepSeek Harness**（必须重启，Host 进程只在启动时加载插件代码）。
2.  发送任意消息，等待一个回合结束，应弹出"会话完成"通知。
